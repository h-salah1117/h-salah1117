## What I build

### 🕌 Online Efteely

A production RAG chatbot that answers Islamic questions from **50,000+ real fatwa records**, a dataset I scraped, cleaned and published on Kaggle. Each fatwa is chunked and embedded with **bge-m3**, stored in ChromaDB, and answered by **gpt-oss-120b** (via Groq) with numbered citations to the source fatwas. A small router model rewrites follow-up questions so retrieval works across a conversation. Traced with LangSmith and running on Hugging Face Spaces.
