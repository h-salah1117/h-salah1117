## What I build

### 🕌 Online Efteely

A production Arabic RAG chatbot: ask an Islamic question in Arabic and it answers from **50,000+ real fatwa records**, a dataset I collected and published on Kaggle. Built with LangChain, ChromaDB, multilingual-e5 embeddings and Llama 3.3 (via Groq), running on Hugging Face Spaces.
